{% callout title="Check Your Version:" %}
This article applies to all MetaDefender Sandbox V2 releases deployed on Linux systems.
{% /callout %}

Browse MetaDefender Sandbox [Release Notes](https://www.opswat.com/docs/filescan/release-notes/release-notes-latest) for details on the latest version, version history, version comparisons and release notes.

Alternatively, go directly through the [My OPSWAT](https://my.opswat.com/portal) for a list of available downloads.:

1. Login to My OPSWAT portal
2. Click on “MetaDefender Sandbox”

{% image url="../../assets/e82a0bc7009c8bb44d1b96ba3e28ce1ca2866361.png" /%}

3. Click on “Download” button

{% image url="../../assets/8fe119b4684d1deb2d59aae8db6ac8f40cd1edab.png" /%}

4. In the new window opened, always the version from the top is the latest version

{% image url="../../assets/617119e3e9f8fb9eda206b8d09ec35a142d1807c.png" /%}

{% callout type="success" title="Pro Tip: " %}
OPSWAT highly recommends that users upgrade to the latest version of MetaDefender Sandbox. Current versions incorporate state-of-the-art features and necessary bug fixes, and are freely available for all license holders to download.
{% /callout %}
