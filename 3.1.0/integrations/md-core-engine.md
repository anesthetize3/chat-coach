MetaDefender Aether technology is available as part of an integration with [MetaDefender Core](https://docs.opswat.com/mdcore). The integration is available with two different engine types: **embedded** and **remote**. The embedded engine is deployed with MetaDefender Core, similar to other engines (CDR/DLP). The remote engine requires a side-by-side installation of the full standalone sandbox platform.
