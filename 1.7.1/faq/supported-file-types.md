A wide range of documents (e.g. Office OOXML, PDFs), scripts (VBS, Jscript, Powershell) and executable file formats (e.g. PE, APK). In general, any file can be submitted, but your results may vary. The best coverage is performed for Office files.

More details about supported file types are available [here](https://docs.opswat.com/filescan/datasheet/supported-file-types).
