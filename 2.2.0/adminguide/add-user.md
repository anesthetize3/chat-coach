In this section, you will be shown how to add user to Filescan.io.

{% callout title="Right to add users to Filescan.io" %}
Only Admins are able to invite users and give certain right to those users.
{% /callout %}

### Step 1 - Go to "Admin panel"

Go to your "**Admin panel**" by clicking on Your account icon on the top right corner.

{% image url="https://uploads.developerhub.io/prod/XX2D/8ox7f0bqglekj4otynbh50nrqu1xfcfw3uwnjtar10dtts4tfso08sttrwju1kwg.png" %}
*Filescan.io Homepage*
{% /image %}

### Step 2 - Select "User Management"

After you arrive to the Report Statistics Dashboard, where you can select "**User Management**" on the top left area of the menu bar.

{% image url="https://uploads.developerhub.io/prod/XX2D/m4grpyl05emo5sqanumxg24whtiok9orzesafcsr6zdcxzjvcxvmir6od9qmgkes.png" /%}

### Step 3 - Click on "Invite user"

By selecting "Invite user", you will get a pop-up window.

{% image url="https://uploads.developerhub.io/prod/XX2D/wjc8v36ryjrchncuhy0vrg02p9i4tsqj757wgysid80hmjbd02nf3b63h3n77sdq.png" %}
*User management dashboard*
{% /image %}

{% image url="https://uploads.developerhub.io/prod/XX2D/0z5lanv10xudrckhmp325iyw7vd7wqpvtj0bao302jti6pip0s0aqqt0bzyic0yw.png" %}
*Invitation link pop-up*
{% /image %}

### Step 4 - Generate invitation link

You may choose between the following user group  type to generate link for the designated Filescan.io user

- Admin
- Auditor
- Intel
- User
- Guest
