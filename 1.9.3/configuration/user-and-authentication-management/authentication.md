These are the unique strings of characters generated by an authentication system for MetaDefender Sandbox after a user successfully logs in. Instead of using the username and password for every request, the server issues a token that represents the user's authenticated session.

{% cell %}
External tokens are tokens issued by an external service or system for the purpose of authentication or authorization. Such tokens are encrypted before it is saved to the database.
{% /cell %}
{% /row %}
{% row %}
{% cell %}
*INTERNAL\_TOKENS\_SECRET\_KEY*
{% /cell %}
{% cell %}
Internal tokens are used internally within the sandbox for specific tasks like authentication and password resets. Encrypting these tokens with a secret key adds a layer of security, and decrypting them allows us to verify their authenticity when users interact with MetaDefender Sandbox. *(encrypted before usage)*
{% /cell %}
