MetaDefender Aether now allows users to set their preferred timezone and locale.

Users can navigate to **My Settings \> Preferences**

## Step 1

Go to the **Admin Panel** icon and choose the **My settings** menu option.

{% image url="https://uploads.developerhub.io/prod/XX2D/83ejztd1l6vmy6mwnqgx25vsrgp4jhc3r4rvyrpdn10edep5o71coiul0jt76pn0.png" /%}

## Step 2

Select the **Professional Info** \> **Preferences** tab to set the preferred Timezone as well as Locale (date format).

Note that the default settings match your browser/system configuration.

{% image url="../../assets/b62a5b44e4acbec1426234654669538408161d02.png" /%}

All timestamps on the Aether UI should be displayed following the timezone/locale configuration. For example:
