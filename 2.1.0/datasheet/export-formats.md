The MetaDefender Sandbox supports exports in the following formats:

- HTML
- PDF
- MISP JSON
- STIX JSON

The preferred format can be selected on the report page by clicking "Download Report":

{% image url="https://uploads.developerhub.io/prod/XX2D/yhnkcpll5xxzikwbezgxtqtez8wzgigktfodkunnwkgb5qug119yl58e04n0khgr.png" /%}

{% callout type="warning" title="Note" %}
The export process may take several minutes, depending on the size of the report and its contents. This duration is largely influenced by the selected settings, such as whether to include interesting strings or not
{% /callout %}

In case of **PDF** or **HTML**, the exported files can be downloaded from *"My Downloads"* :

{% image url="https://uploads.developerhub.io/prod/XX2D/r873xccs5jv4dix88uq17qnlm11aqv9nqlq2hzvhbyhj0oy2up3r8aoaje8uokel.png" /%}
