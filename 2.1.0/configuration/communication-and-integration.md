Communication and integration settings can also be specified under the admin panel  (User -\> Admin panel -\> Settings). These include the following:

- [Providers](communication-and-integration/providers.md) settings, such like MetaDefender Cloud
- [Reputation](communication-and-integration/reputation.md) settings, such as the threshold for various provider verdicts, bulk limit, or limits for IOC reports
- [SMTP / Email](communication-and-integration/email.md) configurations
- [Chat GPT](communication-and-integration/chat-gpt.md) authentication and fine-tuning settings
- [OCM](communication-and-integration/ocm.md), OPSWAT Central Management settings, like timeout and URL
- [MISP](communication-and-integration/misp.md) integration settings, like API-key or URL
