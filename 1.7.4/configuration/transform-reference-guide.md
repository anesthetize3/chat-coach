The transform processor node is the heart of the system, as it contains the in-depth analysis capabilities (e.g. extracting embedded files from OLE containers, decompiling JAR files, etc.), most of the third-party service integrations (e.g. OSINT lookups) and consequently a wide range of configuration options. In the following section, the file structure and engine options will be outlined.
