In the admin panel, there are several options to configure user and authentication management (User -\> Admin panel -\> Settings). Such options include

- [Authentication](user-and-authentication-management/authentication.md), where internal and external token keys can be generated
- [Terms of Use](user-and-authentication-management/terms-of-use.md), where you can configure various usage terms, such as several Termly settings
- and [Third Party](user-and-authentication-management/third-party.md) components, like Google Analytics
