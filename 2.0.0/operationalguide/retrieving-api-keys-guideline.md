An extensive API and OpenAPI (OAS3) Documentation is available from the [API](https://www.filescan.io/api/docs) link at the top menu. You can generate your API key for authorization at the API Key tab of your [profile settings](https://www.filescan.io/users/profile).

Users can navigate to **My Settings \> API Keys**

## Step 1

Go to the **Admin Panel** icon and choose the **My settings** menu option.

## Step 2

Select the **API Key** tab in order to retrieve, change or remove the API keys.
