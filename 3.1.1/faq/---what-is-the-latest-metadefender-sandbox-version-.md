{% callout title="Check Your Version:" %}
This article applies to all MetaDefender Aether releases deployed on Linux systems.
{% /callout %}

Browse MetaDefender Aether [Release Notes](https://www.opswat.com/docs/filescan/release-notes/release-notes-latest) for details on the latest version, version history, version comparisons and release notes.

Alternatively, go directly through the [My OPSWAT](https://my.opswat.com/portal) for a list of available downloads.:

1. Login to My OPSWAT portal
2. Click on “MetaDefender Aether”

{% image url="../../assets/2d8f0521def141d8a84cd5904a5c8984bc6b0c0d.png" /%}

3. Click on “Download” button

{% image url="../../assets/6949638bb78b93ada8e67b1bdf597c9922a8f2f0.png" /%}

4. In the new window opened, always the version from the top is the latest version

{% image url="../../assets/200385503a52a0d9e58830a5840494209e6f51ec.png" /%}

{% callout type="success" title="Pro Tip: " %}
OPSWAT highly recommends that users upgrade to the latest version of MetaDefender Aether. Current versions incorporate state-of-the-art features and necessary bug fixes and are freely available for all license holders to download.
{% /callout %}
