Here you will be shown how to remove user accounts from MetaDefender Aether if it is no longer needed.

{% callout title="Removing a user account on MetaDefender Aether" %}
The right to remove a user account is only available for Admins.
{% /callout %}

### Step 1 - Go to "Admin Panel"

Go to your "**Admin panel**" by clicking on Your account icon on the top right corner.

{% image url="../../assets/f17d57b733c42ccc5ab02bc56d0c4345d4a81e47.png" /%}

### Step 2 - Select "User Management"

After you arrive to the Report Statistics Dashboard, where you can select "**User Management**" on the top left area of the menu bar.

{% image url="../../assets/31bce33e03190383e7aab00a911a7706ac34b120.png" /%}

### Step 3 - Find the user to be deleted

You can type the user / email address of the user that needs to be removed from the platform. You can use the red trash can icon to delete the user.

{% image url="../../assets/d705c6e4959122165d85cb584a1c6acee5c4111b.png" /%}

### Step 4 - Remove the user

The pop-up window allows you to confirm the user that you wish to remove from the platform. After that you need to click "**Delete**", if you want to delete the user. If not, hit "**Cancel**"

{% image url="../../assets/074721500a7dfdc1255cd24863a6974842197dbe.png" /%}
