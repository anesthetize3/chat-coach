The configuration of data management is also accessible from the admin panel  (User -\> Admin panel -\> Settings), such as database settings, storage settings, retention policy, or secondary storage. The following are included under data management:

- [Database](data-management/database.md) settings
- [Storage](data-management/storage.md) settings
- [Retention Policy Configuration](data-management/retention-policy-configuration.md)
- [S3 Report Storage](data-management/s3-report-storage.md) settings (for secondary storage)
